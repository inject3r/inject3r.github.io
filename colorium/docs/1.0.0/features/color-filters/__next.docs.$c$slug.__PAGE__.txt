# Color Filters

Colorium provides a comprehensive set of color filters for transforming and enhancing colors. This guide covers all available filters and their usage.

## Overview of Filters

| Filter       | Purpose                    | Use Case                     |
| ------------ | -------------------------- | ---------------------------- |
| Sepia        | Warm vintage effect        | Photo effects, retro styling |
| Grayscale    | Black and white conversion | Photo effects, accessibility |
| Invert       | Negative effect            | Photo effects, dark mode     |
| Contrast     | Adjust contrast            | Image enhancement            |
| Brightness   | Adjust brightness          | Image enhancement            |
| Saturation   | Adjust color intensity     | Color grading                |
| Hue Rotation | Shift colors               | Color effects                |
| Posterize    | Reduce color levels        | Artistic effects             |
| Temperature  | Warm/cool adjustment       | Color grading                |
| Vignette     | Edge darkening             | Photo effects                |

## Basic Filters

### Sepia Filter

Creates a warm, vintage brownish tone.

```python
from colorium import Color, SepiaFilter

color = Color(200, 150, 100)

# Create sepia filter with intensity
sepia = SepiaFilter(intensity=0.7)
result = sepia(color)

# Different intensities
light_sepia = SepiaFilter(0.3)
heavy_sepia = SepiaFilter(1.0)

# Apply filter
result = heavy_sepia(color)
print(result.to_hex_string())
```

### Grayscale Filter

Converts colors to black and white.

```python
from colorium import Color, GrayscaleFilter

color = Color(255, 0, 0)

# Three conversion methods
luminance = GrayscaleFilter("luminance")  # Perceptual (recommended)
average = GrayscaleFilter("average")      # Simple average
lightness = GrayscaleFilter("lightness")  # Lightness method

result = luminance(color)
print(result.to_hex_string())  # Gray value
```

### Invert Filter

Creates a negative effect.

```python
from colorium import Color, InvertFilter

color = Color(255, 0, 0)

# Invert the color
invert = InvertFilter()
result = invert(color)

print(result.to_hex_string())  # #00FFFF (cyan)
```

### Contrast Filter

Adjusts the difference between light and dark areas.

```python
from colorium import Color, ContrastFilter

color = Color(100, 150, 200)

# Increase contrast
high_contrast = ContrastFilter(1.5)
result = high_contrast(color)

# Decrease contrast
low_contrast = ContrastFilter(0.5)
result = low_contrast(color)

# Values: 0.1 to 3.0
extreme = ContrastFilter(3.0)
```

### Brightness Filter

Adjusts the overall brightness.

```python
from colorium import Color, BrightnessFilter

color = Color(100, 150, 200)

# Increase brightness
brighter = BrightnessFilter(1.5)
result = brighter(color)

# Decrease brightness
darker = BrightnessFilter(0.5)
result = darker(color)

# Values: 0.0 to 2.0
max_bright = BrightnessFilter(2.0)
```

## Advanced Filters

### Saturation Filter

Controls the intensity of colors.

```python
from colorium import Color, SaturationFilter

color = Color(100, 150, 200)

# Increase saturation
vivid = SaturationFilter(0.5)
result = vivid(color)

# Decrease saturation
muted = SaturationFilter(-0.5)
result = muted(color)

# Full desaturation
gray = SaturationFilter(-1.0)
result = gray(color)
```

### Hue Rotation Filter

Shifts all colors around the color wheel.

```python
from colorium import Color, HueRotateFilter

color = Color(255, 0, 0)  # Red

# Rotate hue by degrees
rotate_90 = HueRotateFilter(90)
result = rotate_90(color)  # Greenish

rotate_180 = HueRotateFilter(180)
result = rotate_180(color)  # Cyan

# Any angle (0-360)
rotate_45 = HueRotateFilter(45)
```

### Posterize Filter

Reduces the number of color levels.

```python
from colorium import Color, PosterizeFilter

color = Color(100, 150, 200)

# Levels: 2-256
posterize_4 = PosterizeFilter(4)
result = posterize_4(color)

posterize_8 = PosterizeFilter(8)
posterize_16 = PosterizeFilter(16)

# Higher levels = less effect
identity = PosterizeFilter(256)  # No effect
```

### Temperature Filter

Adjusts warm/cool balance.

```python
from colorium import Color, TemperatureFilter

color = Color(200, 200, 200)

# Warm (lower Kelvin)
warm = TemperatureFilter(3000)  # 3000K
result = warm(color)

# Cool (higher Kelvin)
cool = TemperatureFilter(8000)  # 8000K
result = cool(color)

# Neutral (5500K)
neutral = TemperatureFilter(5500)
result = neutral(color)
```

### Vignette Filter

Darkens the edges.

```python
from colorium import Color, VignetteFilter

color = Color(200, 150, 100)

# Create vignette effect
vignette = VignetteFilter(intensity=0.5)
result = vignette(color)

# Stronger vignette
strong_vignette = VignetteFilter(1.0)
result = strong_vignette(color)
```

## Composite Filters

Chain multiple filters together.

```python
from colorium import Color, CompositeFilter
from colorium import SepiaFilter, ContrastFilter, BrightnessFilter

color = Color(200, 150, 100)

# Create a vintage effect
vintage = CompositeFilter([
    SepiaFilter(0.5),
    ContrastFilter(1.1),
    BrightnessFilter(0.9)
])

result = vintage(color)

# Add more filters
vintage.add_filter(BrightnessFilter(1.05))
result = vintage(color)
```

## Custom Filters

### Creating Custom Matrix Filters

```python
from colorium import MatrixFilter, Color

# Create a custom matrix
gray_matrix = (
    0.299, 0.587, 0.114,
    0.299, 0.587, 0.114,
    0.299, 0.587, 0.114
)

gray_filter = MatrixFilter(gray_matrix, "CustomGrayscale")
result = gray_filter(Color(255, 0, 0))
```

### Creating Custom Composite Filters

```python
from colorium import CompositeFilter
from colorium import SepiaFilter, ContrastFilter, BrightnessFilter

def create_custom_filter():
    """Create a custom filter combination"""
    return CompositeFilter([
        SepiaFilter(0.3),
        ContrastFilter(1.2),
        BrightnessFilter(1.1),
        SaturationFilter(0.2)
    ], name="CustomVintage")

my_filter = create_custom_filter()
result = my_filter(color)
```

## Batch Processing

Apply filters to multiple colors.

```python
from colorium import Color, SepiaFilter

colors = [
    Color(100, 150, 200),
    Color(255, 0, 0),
    Color(0, 255, 0)
]

filter = SepiaFilter(0.7)

# Apply to all colors
results = filter.apply_to_batch(colors)

for original, filtered in zip(colors, results):
    print(f"{original.to_hex_string()} → {filtered.to_hex_string()}")
```

## Advanced Usage

### Filter Combinations

```python
from colorium import Color, CompositeFilter

def create_style_effect(style):
    """Create different style effects"""
    styles = {
        'retro': [
            SepiaFilter(0.6),
            ContrastFilter(0.9),
            BrightnessFilter(1.05)
        ],
        'modern': [
            ContrastFilter(1.2),
            SaturationFilter(0.3),
            HueRotateFilter(-10)
        ],
        'dramatic': [
            GrayscaleFilter("luminance"),
            ContrastFilter(1.4),
            BrightnessFilter(0.9)
        ]
    }

    return CompositeFilter(
        styles.get(style, [SepiaFilter(0.5)]),
        name=style.capitalize()
    )

# Use different styles
retro = create_style_effect('retro')
modern = create_style_effect('modern')
dramatic = create_style_effect('dramatic')
```

### Dynamic Filter Creation

```python
from colorium import ColorFilter, CompositeFilter

def create_filter_chain(filters_config):
    """Create a filter chain from configuration"""
    filter_map = {
        'sepia': SepiaFilter,
        'contrast': ContrastFilter,
        'brightness': BrightnessFilter,
        'saturate': SaturationFilter,
        'grayscale': GrayscaleFilter
    }

    filters = []
    for filter_name, params in filters_config.items():
        if filter_name in filter_map:
            filter_class = filter_map[filter_name]
            filters.append(filter_class(**params))

    return CompositeFilter(filters)

config = {
    'sepia': {'intensity': 0.5},
    'contrast': {'amount': 1.2},
    'brightness': {'amount': 1.1}
}

filter_chain = create_filter_chain(config)
result = filter_chain(color)
```

### Filter Performance

```python
from colorium import Color, SepiaFilter
import time

color = Color(200, 150, 100)
filter = SepiaFilter(0.7)

# Apply filter multiple times
start = time.time()
for _ in range(1000):
    result = filter(color)
end = time.time()

print(f"Time for 1000 filters: {end - start:.3f}s")
```

## Best Practices

### Reuse Filters

```python
# Good - reuse filter
filter = SepiaFilter(0.7)
result1 = filter(color1)
result2 = filter(color2)

# Avoid - create new filter each time
result1 = SepiaFilter(0.7)(color1)
result2 = SepiaFilter(0.7)(color2)
```

### Chain Filters When Possible

```python
# Good - chain filters
vintage = CompositeFilter([
    SepiaFilter(0.5),
    ContrastFilter(1.1)
])
result = vintage(color)

# Avoid - apply separately
result = SepiaFilter(0.5)(color)
result = ContrastFilter(1.1)(result)
```

### Use Presets for Common Effects

```python
# Good - use presets
vintage = FilterPresets.valencia()
result = vintage(color)

# Avoid - recreate common combinations
vintage = CompositeFilter([
    SepiaFilter(0.15),
    BrightnessFilter(1.05),
    ContrastFilter(0.95)
])
```
