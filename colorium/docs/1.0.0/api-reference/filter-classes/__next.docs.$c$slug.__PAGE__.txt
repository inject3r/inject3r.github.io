# Filter Classes API

This document covers all filter classes and presets available in Colorium.

## Base Classes

### ColorFilter

Abstract base class for all color filters.

```python
class ColorFilter(ABC):
    def __init__(self, name: str = "Filter")
    @abstractmethod
    def apply(self, color: Color) -> Color
    def __call__(self, color: Color) -> Color
    def apply_to_batch(self, colors: List[Color]) -> List[Color]
```

**Methods:**

| Method                   | Description                     |
| ------------------------ | ------------------------------- |
| `apply(color)`           | Apply filter to a single color  |
| `__call__(color)`        | Call filter like a function     |
| `apply_to_batch(colors)` | Apply filter to multiple colors |

**Example:**

```python
from colorium import ColorFilter, Color

class CustomFilter(ColorFilter):
    def apply(self, color: Color) -> Color:
        return Color(255 - color.red, 255 - color.green, 255 - color.blue)

filter = CustomFilter("Invert")
result = filter(color)
```

### MatrixFilter

Filter using a 3x3 transformation matrix.

```python
class MatrixFilter(ColorFilter):
    def __init__(self, matrix: Tuple[float, ...], name: str = "MatrixFilter")
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type              | Description                          |
| --------- | ----------------- | ------------------------------------ |
| matrix    | Tuple[float, ...] | 9 numbers for 3x3 matrix (row-major) |
| name      | str               | Filter name                          |

**Example:**

```python
from colorium import MatrixFilter, Color

# Grayscale matrix
gray_matrix = (
    0.299, 0.587, 0.114,
    0.299, 0.587, 0.114,
    0.299, 0.587, 0.114
)

filter = MatrixFilter(gray_matrix, "Grayscale")
result = filter(Color(255, 0, 0))
```

### CompositeFilter

Filter that applies multiple filters in sequence.

```python
class CompositeFilter(ColorFilter):
    def __init__(self, filters: List[ColorFilter], name: str = "CompositeFilter")
    def apply(self, color: Color) -> Color
    def add_filter(self, filter: ColorFilter) -> None
```

**Parameters:**

| Parameter | Type              | Description                       |
| --------- | ----------------- | --------------------------------- |
| filters   | List[ColorFilter] | List of filters to apply in order |
| name      | str               | Filter name                       |

**Example:**

```python
from colorium import CompositeFilter, SepiaFilter, ContrastFilter

vintage = CompositeFilter([
    SepiaFilter(0.5),
    ContrastFilter(1.1)
], name="Vintage")

result = vintage(color)
```

## Basic Filters

### SepiaFilter

Apply a warm sepia tone effect.

```python
class SepiaFilter(ColorFilter):
    def __init__(self, intensity: float = 1.0)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type  | Range | Description                     |
| --------- | ----- | ----- | ------------------------------- |
| intensity | float | 0-1   | Filter intensity (default: 1.0) |

**Example:**

```python
from colorium import SepiaFilter

sepia = SepiaFilter(0.7)
result = sepia(color)
```

### GrayscaleFilter

Convert a color to grayscale.

```python
class GrayscaleFilter(ColorFilter):
    def __init__(self, method: str = "luminance")
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type | Description                              |
| --------- | ---- | ---------------------------------------- |
| method    | str  | Conversion method (default: "luminance") |

**Methods:** `"luminance"`, `"average"`, `"lightness"`

**Example:**

```python
from colorium import GrayscaleFilter

luminance = GrayscaleFilter("luminance")
average = GrayscaleFilter("average")
lightness = GrayscaleFilter("lightness")
```

### InvertFilter

Apply invert (negative) effect.

```python
class InvertFilter(ColorFilter):
    def __init__(self)
    def apply(self, color: Color) -> Color
```

**Example:**

```python
from colorium import InvertFilter

invert = InvertFilter()
result = invert(color)
```

### ContrastFilter

Adjust contrast of a color.

```python
class ContrastFilter(ColorFilter):
    def __init__(self, amount: float = 1.2)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type  | Range   | Description                    |
| --------- | ----- | ------- | ------------------------------ |
| amount    | float | 0.1-3.0 | Contrast amount (default: 1.2) |

**Example:**

```python
from colorium import ContrastFilter

high_contrast = ContrastFilter(1.5)
low_contrast = ContrastFilter(0.5)
```

### BrightnessFilter

Adjust brightness of a color.

```python
class BrightnessFilter(ColorFilter):
    def __init__(self, amount: float = 1.2)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type  | Range | Description                          |
| --------- | ----- | ----- | ------------------------------------ |
| amount    | float | 0-2.0 | Brightness multiplier (default: 1.2) |

**Example:**

```python
from colorium import BrightnessFilter

brighter = BrightnessFilter(1.5)
darker = BrightnessFilter(0.5)
```

## Advanced Filters

### SaturationFilter

Adjust saturation of a color.

```python
class SaturationFilter(ColorFilter):
    def __init__(self, amount: float = 0.5)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type  | Range   | Description                          |
| --------- | ----- | ------- | ------------------------------------ |
| amount    | float | -1 to 1 | Saturation adjustment (default: 0.5) |

**Example:**

```python
from colorium import SaturationFilter

vivid = SaturationFilter(0.5)
muted = SaturationFilter(-0.5)
gray = SaturationFilter(-1.0)
```

### HueRotateFilter

Rotate hue of a color.

```python
class HueRotateFilter(ColorFilter):
    def __init__(self, degrees: float = 90)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type  | Range | Description                         |
| --------- | ----- | ----- | ----------------------------------- |
| degrees   | float | 0-360 | Degrees to rotate hue (default: 90) |

**Example:**

```python
from colorium import HueRotateFilter

rotate_90 = HueRotateFilter(90)
rotate_180 = HueRotateFilter(180)
```

### PosterizeFilter

Reduce number of color levels.

```python
class PosterizeFilter(ColorFilter):
    def __init__(self, levels: int = 4)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type | Range | Description                           |
| --------- | ---- | ----- | ------------------------------------- |
| levels    | int  | 2-256 | Color levels per channel (default: 4) |

**Example:**

```python
from colorium import PosterizeFilter

posterize_4 = PosterizeFilter(4)
posterize_8 = PosterizeFilter(8)
```

### TemperatureFilter

Adjust color temperature.

```python
class TemperatureFilter(ColorFilter):
    def __init__(self, kelvin: int = 5500)
    def apply(self, color: Color) -> Color
```

**Parameters:**

| Parameter | Type | Range      | Description                       |
| --------- | ---- | ---------- | --------------------------------- |

**Example:**


### VignetteFilter

Darken edges of an image.

```python
class VignetteFilter(ColorFilter):
```

| intensity | float               | 0-1   | Vignette intensity (default: 0.5)     |


## Filter Composition

### Chaining Filters

```python
from colorium import CompositeFilter, SepiaFilter, ContrastFilter, BrightnessFilter

# Create custom filter chain
custom = CompositeFilter([
    SepiaFilter(0.5),
    ContrastFilter(1.2),
    BrightnessFilter(1.1)
], name="Custom")

result = custom(color)
```

### Adding Filters Dynamically

```python
from colorium import CompositeFilter, SepiaFilter, ContrastFilter

filter = CompositeFilter([], name="Dynamic")

# Add filters dynamically
filter.add_filter(SepiaFilter(0.5))
filter.add_filter(ContrastFilter(1.2))

result = filter(color)
```

### Creating Reusable Filters

```python
from colorium import CompositeFilter, SepiaFilter, ContrastFilter

def create_vintage_filter(intensity=0.5, contrast=1.1):
    """Create a reusable vintage filter"""
    return CompositeFilter([
        SepiaFilter(intensity),
        ContrastFilter(contrast)
    ], name=f"Vintage_{intensity}_{contrast}")

# Create multiple variants
light_vintage = create_vintage_filter(0.3, 1.0)
medium_vintage = create_vintage_filter(0.5, 1.1)
heavy_vintage = create_vintage_filter(0.7, 1.2)
```
