Getting Started

Install in seconds and start building executables.

Installation

pip install --upgrade pyinstaller-gui

Or clone the repository directly:

git clone https://github.com/inject3r/pyinstaller-gui.git
cd pyinstaller-gui
pip install -e .

Launching the GUI

pyinstaller-gui

Or use the shorthand:

pyinstallergui

Converting a Script

  1. Open the PyInstaller GUI application.
  2. Load your Python script by clicking Browse, dragging and dropping a .py file, or selecting from Recent files.
  3. Configure your build options across the tabs: General, Additional Files, Advanced, Settings, and Config.
  4. Click Run PyInstaller to generate the executable.

Configuration Management

  • Export Configuration: Save your current settings as a JSON file.
  • Import Configuration: Load previously saved settings.
  • Preview: View a human-readable summary of your current configuration.

Keyboard Shortcuts and Tips

  • Double-click any file in the Additional Files list to edit its path.
  • Use the Search box to filter files in the Additional Files tab.
  • Copy button copies the generated command to clipboard.
  • Save Log saves the build output to a file with timestamp.
  • Clear button clears the output console.

Troubleshooting

Common issues and their solutions.

PyInstaller not found
Install with pip install pyinstaller.
Module not found errors
Add missing modules to Hidden Imports.
Icon not showing
Ensure icon format is correct (.ico for Windows, .icns for macOS).
Permission denied on Linux
Run chmod +x dist/your_app.
Command preview shows error
Check if script path is valid and file exists.
Build fails with no console
GUI applications need --windowed flag (already set by No Console option).

Running Tests

./scripts/tests.sh

# Clean test output files
./scripts/test_clean.sh

# Run a single test file
python -m pytest tests/test_command_builder.py -v

Building from Source

# Install in development mode
pip install -e .

# Install with dev dependencies
pip install -e ".[dev]"

# Build distribution
python -m build

# Build executable with PyInstaller
pyinstaller pyinstaller-gui.spec
