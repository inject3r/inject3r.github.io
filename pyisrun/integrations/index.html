Real integration surfaces

This page lists interfaces that are present in the source tree. It does not imply official integrations with third-party frameworks that are not shipped here.

Cross-platform code paths exist for POSIX and Windows, but the repository states that native builds are only verified on Linux x86-64; non-Linux/non-x86 targets are untested.

Python buffer protocol

MemBlock exposes a native buffer. memoryview(block), bytes(block), and buffer consumers such as NumPy can operate on it; slicing returns zero-copy views.

import numpy as np
from pylsrun import memory

block = memory.malloc(1024)
view = memoryview(block)
arr = np.frombuffer(block, dtype=np.uint8)

ctypes-compatible function addresses

JIT Executable objects expose an address, and as_ctypes_function turns an Executable into a callable ctypes function pointer.

import ctypes
from pylsrun import jit

exe = jit.Executable(code)
fn = jit.as_ctypes_function(exe, restype=ctypes.c_long)

Shared libraries through libffi

abi.Library resolves symbols from a shared library; call_native describes arguments with PylsRun typecodes and calls the function through libffi. The shown library name is a Linux example.

from pylsrun import abi

# Linux example
lib = abi.Library("libm.so.6")
sqrt = lib.symbol("sqrt")
value = abi.call_native(sqrt, ["f64"], [2.0], ret_typecode="f64")

SIMD over buffer-protocol objects

Native SIMD entry points accept buffer-protocol objects directly, including array.array, bytearray, MemBlock, and compatible NumPy arrays.

import array
from pylsrun import simd

a = array.array("f", [1.0] * 8)
b = array.array("f", [2.0] * 8)
out = array.array("f", [0.0] * 8)
simd.add_f32(a, b, out, 8)

Host compiler integration

The compile-time subsystem can query the host C++ compiler for constexpr expressions, type sizes, alignments, and struct layouts. It does not provide a general C++ kernel compiler API.

from pylsrun import ctime

answer = ctime.eval_constexpr("6 * 7")
size = ctime.sizeof("double")
alignment = ctime.alignof("long double")

Python threading + native synchronization

The native concurrency primitives can be used from Python threading.Thread. Blocking native synchronization calls release the GIL; NativeThread is also available for native function pointers.

import threading
from pylsrun import concurrency

mu = concurrency.Mutex()

with mu:
    # protect shared native memory
    pass
